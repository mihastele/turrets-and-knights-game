Coupon guide

Back to game

Support the game at Buy Me a Coffee. The admin will send your coupon privately. Redeem it in the lobby to unlock the Dragon and Valkyrie with their upgrades, the Rockslide, Dragon Fire and Warcry Blessing field effects, and Elite Doctrine unit/tower specials until it expires.

New coupons have the form DRGN-XXXX-XXXX-XXXX. Existing shorter coupons remain valid. Remove saved coupons from the lobby with Remove saved coupons. Selecting Play without coupon also removes saved coupons from this browser.

Each match start uses one coupon use. The final use remains active for that match and is removed from this browser. Expired coupons are removed from the server store and browser.

Create a coupon in Postman

  1. Set LANESIEGE_ADMIN_TOKEN and start the server.
  2. Create a POST request to http://localhost:8180/api/admin/coupons.
  3. Choose Bearer Token under Authorization and enter the admin token.
  4. Choose raw JSON under Body and send the example below.
{"label":"Supporter coupon","validDays":30,"maxUses":10}

The 201 response contains the coupon code. Send it privately. validDays counts 24-hour periods from creation and accepts 1–3650. Omitted or zero defaults to 30 days. maxUses defaults to 10 match starts and zero means unlimited match starts.

Use GET /api/admin/coupons to list codes and POST /api/admin/coupons/{code}/revoke to revoke a code. Both require the bearer token.
